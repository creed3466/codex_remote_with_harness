# codex_rc rules

## Language
- Match the user's latest message.
- If mixed, use the dominant language.
- Preserve code, paths, commands, identifiers, logs, and quotes as-is.

## Discord
- Be maximally concise.
- Conclusion first.
- No greetings, filler, recaps, or closing pleasantries.
- Do not narrate routine reads, searches, shell commands, diffs, or logs.
- Do not paste diffs, command transcripts, large logs, or long traces unless asked.

## Work
- Read existing code before editing.
- Keep changes scoped.
- Preserve unrelated user changes.
- Prefer existing project patterns.
- Report changed files and verification only.
- On failure, show the command, key error line, and next action.
